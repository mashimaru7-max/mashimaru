# 덕덕 합체

Go-Go! Duck 스타일을 참고한 독립형 1인 웹게임. 사이트 로그인·DC 포인트와 연결하지 않습니다.

## 실행 및 통합

`duck-merge/` 폴더 전체를 정적 웹서버에 올리고 `index.html`을 엽니다. GitHub Pages에서는 기존 사이트 하위 경로 `/duck-merge/`로 실행됩니다. 상대 경로만 사용하므로 다른 사이트로 폴더를 복사하거나 iframe으로 넣을 수 있습니다.

`<iframe src="/duck-merge/" title="덕덕 합체" style="width:100%;height:100dvh;border:0"></iframe>`

화면 폭에 맞춰 게임판이 줄어들며 물리 좌표는 고정됩니다. 휴대폰에서는 이동 후 손을 떼면 낙하, PC에서는 클릭 또는 방향키·스페이스를 사용합니다. 최고 점수와 소리 설정만 현재 브라우저에 저장합니다. 소리는 최초 기본 꺼짐입니다.

## 구성

- `physics.js`: Matter.js 0.20.0 기반 고정 120Hz 물리, 합체 큐, 입력 대기, 경계선 판정
- `game.js`: Canvas 렌더링, 픽셀 오리 아틀라스 로딩, UI, 터치, 키보드, 효과음, 브라우저 저장
- `style.css`, `index.html`: 반응형 UI
- `assets/duck-1.png` ~ `duck-8.png`: 미리 준비한 투명 RGBA 오리 이미지. 실행 중 이미지 가공 없음.
- `graphics.js`: 8종 이미지 일괄 로딩, 재시도, 몸통 기준 렌더링, 그리기 오류 일시정지.
- `assets/ducks.webp`, `scripts/build_sprites.py`: 보관된 원본 아틀라스와 에셋 빌드 스크립트. 게임 실행 시 사용하지 않음.
- `vendor/`: 자체 호스팅한 Matter.js와 MIT 라이선스. 실행 중 물리 엔진 CDN 의존 없음

## 규칙

아기 → 기본 → 리본 → 탐험가 → 마법사 → 천사 → 우주 → 대왕 (8단계).
새 과일 대신 작은 오리 1~4단계가 등장합니다. 처음 두 번은 아기 오리입니다.
같은 단계 둘이 접촉하면 합체하고 새 단계 점수를 얻습니다. 마지막 대왕 오리 둘은 합체하지 않습니다.
투하 후 1.8초 유예, 합체 후 1초 유예를 두며, 그 후 한 오리가 경계선 위에 3초 연속 머물면 종료합니다.
창을 벗어나면 일시정지됩니다. 다시 시작할 때 현재 판 초기화를 확인합니다.

## 검증

`node --test tests/*.test.cjs`
`node --check game.js`

폰 실기기에서는 터치 취소·화면 회전·소리 재생도 확인해주세요. 온라인 랭킹/보상 검증은 포함하지 않습니다.

## WebMCP (지원 브라우저만)

`duck_game_state`: 판 상태 읽기. `drop_duck`: x=0~420 위치에 실제 입력과 동일하게 낙하. 미지원 브라우저에서는 일반 게임 기능에 영향 없습니다.


## v2.1 수정 및 검증

- 수면 기능을 꺼서 합체 후 받침이 없어진 오리가 계속 공중에 남는 문제 해결.
- 실제 원형 접촉을 매 스텝 재검사. 0.5 물리 픽셀 이내의 접촉 여유만 허용하며 110ms 생성 보호가 끝난 쌍을 재검토.
- 장식이 아니라 몸통 영역의 중심과 지름을 충돌 원에 맞춤. `?debug=1`로 충돌 원 표시.
- 로딩 중 8종 이미지가 모두 정상 디코딩되어야 입력 허용. 동시 복구 요청은 하나로 합침.
- 렌더링 오류와 Canvas context loss에서 물리를 멈추고 이미지 복구 버튼 표시. 화면 복귀 시 이미지 갱신 후 기존 판으로 계속 가능.
- 기존 최고 점수 저장 키 유지. 게임판 상태는 복구 중 메모리에서 유지하지만 페이지 완전 새로고침 후 현재 판 복원은 지원하지 않음.
- 기본 물리, 문제 재현, 그래픽 로딩 실패, UI lifecycle, PNG 무결성을 Node 테스트로 검증.
- GitHub 저장소 루트 `.github/workflows/duck-merge-tests.yml`은 관련 경로 변경 시 자동 테스트. 기존 GitHub Pages 배포와는 별도이므로 CI 실패가 Pages 배포를 차단하는 설정은 아님.
- 모든 오리 이미지를 256×256 투명 정사각형에 여백만 추가하고, 가로·세로를 같은 배율로 렌더링. 회전해도 캐릭터가 길어지지 않음.
- 그림의 최대 외곽선과 물리 원의 지름을 거의 일치시켜, 눈으로는 겹치지만 물리적으로 떨어진 상태를 제거.
- 같은 단계의 원형 충돌체는 매 물리 스텝 다시 확인하고 1.5 물리 픽셀 이내의 접촉 오차를 허용. 그 이상의 빈 공간에서는 합체하지 않음.
- 물리 충돌 반복 횟수와 바닥·벽 분리 정확도를 높여 깊은 겹침을 줄임.
- 정사각형·동일 배율·접촉 경계·미합체·깊은 겹침 회귀 테스트를 포함해 총 44개 자동 테스트로 확장.

### 폰 실기기 회귀 확인

삼성 인터넷과 Chrome에서 같은 오리 접촉·고층 받침 합체·20분 플레이·앱 전환 10회·화면 잠금 복귀·가로세로 전환을 확인합니다. 모바일 GPU/브라우저 자체 문제는 Node 테스트만으로 검증되지 않습니다. 그림이 다시 사라지면 브라우저 버전, 기종, 발생 직전 앱 전환 여부와 화면을 기록합니다.
