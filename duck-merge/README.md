# 덕덕 합체

Go-Go! Duck 스타일을 참고한 독립형 1인 웹게임. 사이트 로그인·DC 포인트와 연결하지 않습니다.

## 실행 및 통합

`duck-merge/` 폴더 전체를 정적 웹서버에 올리고 `index.html`을 엽니다. GitHub Pages에서는 기존 사이트 하위 경로 `/duck-merge/`로 실행됩니다. 상대 경로만 사용하므로 다른 사이트로 폴더를 복사하거나 iframe으로 넣을 수 있습니다.

`<iframe src="/duck-merge/" title="덕덕 합체" style="width:100%;height:100dvh;border:0"></iframe>`

화면 폭에 맞춰 게임판이 줄어들며 물리 좌표는 고정됩니다. 휴대폰에서는 이동 후 손을 떼면 낙하, PC에서는 클릭 또는 방향키·스페이스를 사용합니다. 최고 점수와 소리 설정만 현재 브라우저에 저장합니다. 소리는 최초 기본 꺼짐입니다.

## 구성

- `physics.js`: Matter.js 0.20.0 기반 고정 120Hz 물리, 합체 큐, 입력 대기, 경계선 판정
- `game.js`: Canvas 렌더링, 픽셀 오리 아틀라스 로딩, UI, 터치, 키보드, 효과음, 브라우저 저장
- `style.css`, `index.html`: 반응형 UI
- `assets/ducks.webp`: AI 생성 오리 아틀라스. 원본은 유지하며 로드할 때 바깥쪽 연결 배경만 투명하게 렌더링합니다.
- `vendor/`: 자체 호스팅한 Matter.js와 MIT 라이선스. 실행 중 물리 엔진 CDN 의존 없음

## 규칙

아기 → 기본 → 리본 → 탐험가 → 마법사 → 천사 → 우주 → 대왕 (8단계).
새 과일 대신 작은 오리 1~4단계가 등장합니다. 처음 두 번은 아기 오리입니다.
같은 단계 둘이 접촉하면 합체하고 새 단계 점수를 얻습니다. 마지막 대왕 오리 둘은 합체하지 않습니다.
투하 후 1.8초 유예, 합체 후 1초 유예를 두며, 그 후 한 오리가 경계선 위에 3초 연속 머물면 종료합니다.
창을 벗어나면 일시정지됩니다. 다시 시작할 때 현재 판 초기화를 확인합니다.

## 검증

`node --test tests/physics.test.cjs`
`node --check game.js`

폰 실기기에서는 터치 취소·화면 회전·소리 재생도 확인해주세요. 온라인 랭킹/보상 검증은 포함하지 않습니다.

## WebMCP (지원 브라우저만)

`duck_game_state`: 판 상태 읽기. `drop_duck`: x=0~420 위치에 실제 입력과 동일하게 낙하. 미지원 브라우저에서는 일반 게임 기능에 영향 없습니다.
