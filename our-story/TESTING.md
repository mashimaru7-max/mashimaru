# 1차 UI 검증 기록 — 2026-11-13

실행 환경: Chromium 기반 cloud browser, 1348px 데스크톱 뷰와 390×844px iframe(스크롤바 제외 콘텐츠 375px). 실제 Android/iOS 기기 터치와 Safari는 미검증.

## 직접 검증 완료

- 홈 로딩, 로컬 스톡 사진 표시, 홈→여행→성장 탐색.
- OSM 지도 배경 실제 표시, 여행 핀 클릭→프리뷰→상세.
- 국내지도 전환 시 스위스 제외, 국내 예시 2개 표시.
- 모바일 지도 핀 클릭 시 하단 시트 표시 및 닫기.
- 여행 제목/도시 검색, 검색 결과 없는 상태.
- 예시 여행 추가 및 제목 수정 반영.
- 여행 종료일이 시작일보다 빠를 때 저장 차단 후 정상 날짜 저장.
- HTML 태그/이벤트 핸들러 형태 제목이 실행되지 않고 글자로 표시됨.
- 라온 전환 시 라온·함께 기록 표시. 0~2세 선택 시 빈 상태 표시, 전체 복귀.
- 버킷리스트 추가, 체크 상태 반영, 삭제.
- 모바일 성장앨범 이미지 로드 및 body 가로 넘침 없음(375px/375px).
- JS 구문 검사 통과.

## 추가 확인 항목

배포 후 주소와 정적 파일 로드, 갤러리 필터, 기록 삭제, 연결 여행, 성장 추가, 연도/주제 필터는 아래 후속 검증 내용을 기준으로 한다. NAS 원격 호출/인증/서버 저장은 이 단계에 포함되지 않으며 성공으로 간주하지 않는다.

## 보호 범위

커밋 대상은 `our-story/` 새 경로만. 기존 프로젝트와 `nas-photo-test/`, NAS 환경·원본 파일 변경 없음. 브라우저 편집은 메모리 예시이며 원격 저장 요청 없음.

## 인터랙션 / NAS 계약 점검 — 후속 수정

- Leaflet 위치 transform과 핀 그래픽을 분리. SVG 핀·하트에 회전 transform 없음, 좌표는 Leaflet의 translate만 사용함을 브라우저 computed style로 확인.
- 세계지도/국내지도 전환, 확대, 독립된 스위스 핀 클릭→미리보기 내용 변경 확인.
- 국내지도 탭 재렌더 후 선택한 탭에 키보드 포커스가 유지되는 것을 확인.
- 참고 이미지의 패턴을 기준으로 sticky header, hover/press 피드백, 모달·시트·토스트 등장, 홈 스크롤 reveal 및 stagger를 적용. reduced-motion에서는 효과를 끈다.
- NAS 계약 단위 시험 12개 통과. 실제 NAS 접속 검증과 구분하며 자세한 결과는 `docs/NAS-INTEGRATION.md` 참고.
- 390px 모바일 폭: 하트 방향 정상, 핀 클릭 하단 시트와 닫기 동작 확인, 콘텐츠 너비 375px/scrollWidth 375px으로 가로 넘침 없음.
- 모바일 홈 스크롤 후 사진 6개 reveal 완료, sticky header top=0 확인.

## NAS 사진 연결 구현 단계

- 클라이언트 단위 시험 18개 + 기존 API 계약 시험 12개 통과.
- 실제 앱의 NAS 사진 탭, 연결 모달, 토큰/로그인 필드 전환 확인.
- 미배포 QA fixture에서 사진 Blob 디코딩, 목록/경로 탐색, 빈 폴더와 권한 오류, 15MB 제한, 100장 이후 추가, 12장 제한 미리보기, 해제·세션 만료·연결 끊기 확인.
- 모바일 fixture에서 콘텐츠 375px/scrollWidth 375px, 이미지 naturalWidth > 0 확인. 실제 NAS와 혼동하지 않는다.
- 세부 사용 방법과 미검증 경계: `docs/NAS-CONNECT.md`. 원본 NAS 및 기존 서버 파일 변경 없음.
