## 메인 화면 NAS 사진 자동 앨범

기존 갤러리와 수동 대표 사진만 연동되던 범위를 홈·여행·성장까지 확장했다. `docs/AUTO-ALBUMS.md`에 사용 순서와 실제/미구현 범위를 기록했다. JS 51개 통과(자동 탐색 모델 8개 추가). 실제 앱의 의존성만 가상 클라이언트/별도 QA vault로 교체하여 홈 자동 선택/표지, 여행 폴더 하위 사진, 다온·라온·함께 전환, 새 문서 설정 복원, 새 사진 4→5개 갱신, 같은 폴더의 전체 갤러리 진입을 확인했다. 모바일 390px에서 콘텐츠 375px, 가로 넘침 없음. 실제 NAS 접속/성능 검증과 구분한다. 기존 NAS 설정/파일 변경 없음.

구형 API(capabilities 404)에서도 자동 성장앨범 사진 4장 표시 확인. 재연결 시 중단된 로딩이 다시 시작되도록 수정하고 검증했다. 연결 해제 후 홈의 Blob 이미지 0개, 예시 모드 복귀도 확인했다.

홈 대표/표지/앨범의 동시 썸네일 요청을 클라이언트 전체에서 2개로 제한했다. 새 NAS 서비스의 변환 슬롯을 넘지 않도록 공유 큐를 적용하고, 연결 해제 시 대기 중인 요청이 전송되지 않는 시험 2개를 추가했다.

자동 갱신은 목록을 먼저 비교하여 변동이 없으면 원본 사진을 재요청하지 않도록 했다. 실제 poll 메서드를 검증 UI 버튼으로 실행해 요청 수 8→8 유지, 사진 추가 후 4→5개 표시와 요청 수 8→13 변화를 확인했다.
