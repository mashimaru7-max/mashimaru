# 연도별로 흩어진 사진을 폴더 이름으로 모으기

NAS의 원래 정리 방식이 `연도/이름`이어도 폴더를 옮기지 않고 한 앨범에 연결한다. 기존 읽기 전용 `/api/list`와 사진 조회만 사용하며 NAS 서버 설정을 바꾸지 않는다.

## 사용 방법

1. 사이트 새로고침 후 NAS 연결을 유지한다.
2. 성장앨범에서 **함께**를 선택하고 **사진 폴더 연결/변경**을 누른다.
3. 최상위 `/photo`에서 **이름으로 모으기**를 선택한다. 특정 상위 폴더 안에서 선택하면 그 아래만 검색한다.
4. **기본 폴더 이름**에 숫자를 제외한 이름만 입력한다. 예: `아이들사진`.
5. 이름 조건을 **기본 이름 + 숫자 (숫자 없어도 포함)**으로 두고 **이 이름으로 연결**을 누른다.
6. 연도별 일치 폴더를 자동으로 모은다. **폴더 연도**에서 특정 연도를 고르거나 **모은 폴더 전체 보기**에서 각 원본 폴더의 전체 갤러리를 열 수 있다.

`#`는 숫자를 설명하는 기호였으므로 입력할 필요가 없다. 입력한 기본 이름은 정규식/와일드카드로 실행하지 않고 문자 그대로 비교한다.

| 실제 폴더 예시 | 기본 이름이 `아이들사진`일 때 |
| --- | --- |
| 2019/아이들사진 | 포함 |
| 2020/아이들사진1 | 포함 |
| 2021/아이들사진2 | 포함 |
| 2022/아이들사진 4 | 포함 |
| 2023/아이들사진12 | 포함 |
| 2020/아이들사진여행 | 제외 |
| 2020/아이들사진1보관 | 제외 |

추가 조건으로 **이름이 정확히 같음**, **이름에 포함됨**도 제공한다. 기본 숫자 조건은 다른 단어까지 포함하지 않는다. 폴더 이름을 비교하며 사진 파일명이나 얼굴을 분석하지 않는다. 연도는 폴더 경로의 `2019` 또는 `2019년` 같은 이름에서 가져오는 탐색 필터이며 실제 촬영일/나이로 단정하지 않는다.

같은 폴더에 남매 사진이 함께 있다면 함께 앨범에 규칙을 연결한다. 이름 하나만으로 다온·라온의 얼굴을 구분하지 않는다. 여행·홈·아이별 앨범에도 각기 다른 이름 규칙을 설정할 수 있으며 같은 규칙을 지정한 앨범은 같은 사진을 표시한다.

## 자동 갱신과 검색 범위

- 이름 규칙은 기존 폴더 선택과 같은 기기별 암호화 저장소에 보관한다. 기존 고정 폴더 설정과 NAS 연결 기억은 유지한다. 사진이나 검색한 전체 경로 목록을 공개 Git 또는 브라우저 영구 저장소에 기록하지 않는다.
- 연결 origin별로 설정을 분리한다. Quick Tunnel 주소가 바뀌면 현재는 다시 설정해야 하며 다른 기기에는 동기화하지 않는다.
- 폴더 검색 결과는 메모리에서 5분간 재사용한다. 화면을 열어 둔 자동 갱신에서 캐시가 만료되면 새 연도/새 숫자 폴더를 다시 찾는다. **새로 불러오기**를 누르면 즉시 다시 검색한다. 사진 목록은 기존 60초 갱신이며 변화가 없으면 사진을 재다운로드하지 않는다.
- 일치하는 폴더 전체를 먼저 찾은 뒤 여러 폴더에서 미리보기를 나눠 가져온다. 한 폴더의 사진 12장을 찾았다고 다른 연도 검색을 중단하지 않는다. 앨범 화면은 최대 12개(홈 8개) 미리보기이며 모든 사진은 **모은 폴더 전체 보기**에서 각 폴더의 NAS 갤러리로 이어진다.
- 검색은 한 번에 최대 160개 목록 페이지, 깊이 12단계, 대기 경로 5000개 범위다. 큰 NAS에서 검색이 남으면 **남은 폴더 이어서 찾기**를 표시한다. 깊이/대기 경로 제한이면 검색 범위를 좁히라는 안내를 표시한다. 검색하지 못한 범위를 완료했다고 표현하지 않는다.
- 인증 만료/연결 변경 시 검색을 중단하고 결과 및 사진을 정리한다. 일시적인 하위 폴더 권한 오류는 건너뛰되 읽지 못한 폴더가 있음을 표시한다. 검색 중에는 확인한 폴더 수와 일치 수를 표시한다.

## 검증

JS 테스트 총 63개 통과. 이름 조건 3종, 숫자 없는 이름과 여러 자리/공백 앞 숫자, 유사 단어 제외, 정규식 특수문자의 문자 그대로 비교, 여러 연도 발견, 목록 페이지 및 검색 이어가기, 폴더 간 미리보기 분배, 기존 고정 폴더와 규칙의 동시 복원, 연결 종료 후 늦은 결과 폐기를 검사했다.

가상 NAS를 사용한 실제 앱 검증에서는 2019/2020/2021의 숫자 없는 이름·1·2·4 폴더 4개가 모이고 비슷한 다른 단어의 폴더는 빠지는 것을 확인했다. 저장 후 새 문서에서 복원, 2019 필터 사진 6개, 2022/이름7 추가 후 같은 규칙으로 5개 폴더와 새 연도 필터 표시, 원본 폴더의 전체 갤러리로 이동을 확인했다. 모바일 390px iframe 콘텐츠 375px/모달 343px, 가로 넘침 없음·기본 숫자 조건 복원·장식 화살표 0개 확인.

실제 사용자 NAS의 사진/토큰은 이 환경에 없어 실제 NAS 검색 결과와 성능은 미검증이다. 테스트 자료는 가상 폴더와 스톡 이미지이며 NAS 원본과 기존 프로젝트는 변경하지 않았다.
