# NAS 사진 연결과 사진 관리

1. [NAS 사진 보관함](https://mashimaru7-max.github.io/mashimaru/our-story/#nas)으로 이동한다. 저장된 연결은 자동 복원된다. 최초 한 번은 API 주소와 조회 토큰을 입력하고 **이 기기에서 연결 기억**을 체크한다. DSM 비밀번호를 입력하지 않는다.
2. 폴더를 열고 스크롤하면 화면 근처의 사진을 자동으로 불러온다. 12장 제한은 제거했다. 100개 목록의 끝에 도달하면 다음 목록을 자동 요청하며, 수동 **사진 더 불러오기**도 제공한다. 일시 오류에는 **다시 불러오기**를 누른다.
3. 사진을 누르면 확대창에서 **원본 다운로드**, **홈 대표 사진으로**, **휴지통으로 이동**을 선택할 수 있다. 다운로드 파일명은 원래 이름을 사용한다. 실제 저장 완료는 브라우저 다운로드 목록에서 확인한다.
4. 홈 대표 사진은 현재 기기에서만 적용된다. 선택한 사진의 origin/경로/이름을 별도 IndexedDB에 암호화한다. 사진 파일은 저장하지 않는다. 연결을 끊거나 인증이 만료되면 홈의 비공개 사진을 해제하고 스톡 예시로 돌아간다. 홈에서 **대표 사진 해제**를 누르면 선택 기록도 지운다. 다른 기기에는 동기화하지 않는다.
5. **사진 업로드**와 **휴지통**은 관리 API v2의 기능 응답과 쓰기 권한이 모두 있어야 동작한다. 기존 API에서는 설치 필요 안내만 표시한다. 파일을 수정한 것처럼 성공을 표시하지 않는다. 설치 자료는 [NAS 서비스 설명](../nas-service/README.md)과 [ZIP](../downloads/our-story-nas-service.zip)에 있다. 실제 NAS 쓰기 권한 설정은 승인 후 진행한다.
6. 관리 API에서는 업로드할 사진을 여러 장 선택할 수 있다. 순서대로 전송하고 완료/실패 수를 표시한다. 닫으면 전송을 취소하며 이미 완료된 사진은 유지한다. 같은 이름은 덮어쓰지 않는다. 삭제는 확인창 후 휴지통 이동이며 **휴지통 → 복원**으로 되돌린다. 같은 이름이 이미 있으면 복원하지 않는다. 영구 삭제는 없다.

## 저장과 접근 경계

주소·토큰 또는 만료 가능한 API 세션은 AES-256-GCM과 비추출형 CryptoKey로 이 브라우저의 IndexedDB에 보관한다. 비밀번호/실제 사진은 저장하지 않는다. 동일 origin의 다른 스크립트·확장 프로그램으로부터 비밀을 격리한다는 뜻은 아니다. 공개 Git에는 실제 토큰·사진·사진 경로를 넣지 않는다. 연결 정보 삭제는 기기의 기억을 지우며 기존 공유 토큰 자체를 서버에서 폐기하지 않는다. 자세한 내용은 `CONNECTION-MEMORY.md` 참고.

이미지는 인증된 fetch 후 Blob URL로만 표시한다. 스크롤 중 캐시는 최대 48개 또는 64MB를 목표로 화면 밖 항목을 해제한다. 현재 화면 사진은 보호하므로 총 메모리 상한을 보장하지 않는다. 폴더 이동/갤러리 이탈/인증 종료 시 갤러리 Blob을 해제한다. 홈 사진은 홈 이탈/인증 종료 시 해제한다. 동시 미리보기 요청은 2개이며 전체 사진을 한꺼번에 내려받지 않는다.

기존 API의 원본 미리보기/다운로드는 파일당 15MB, 새 API 다운로드는 128MB, 업로드는 64MB 제한이다. JSON은 2MB, 파일 스트림은 선언 크기뿐 아니라 실제 읽은 크기도 검사한다. 썸네일이 없는 API에서는 원본을 내려받으므로 데이터 사용량이 클 수 있다. HEIC/HEIF는 코덱이 없어 브라우저 표시나 서버 썸네일이 실패할 수 있으며 파일 다운로드와 구분한다.

모든 API 요청은 HTTPS Quick Tunnel origin으로만 제한한다. 토큰을 URL이나 이미지 src에 넣지 않는다. 쿠키·리디렉션·캐시는 사용하지 않는다. 경로 검증, 응답 MIME/크기/형식 검증, 요청 세대 검사, 인증 만료 처리와 CSP를 유지한다. 오래된 서버의 `/api/capabilities` 404/405는 읽기 전용으로 처리하며 인증 실패를 숨기지 않는다.

## 실제 NAS 검증 상태와 남은 범위

이번 테스트는 가상 브라우저 API와 임시 디렉터리의 실제 HTTP 서버로 진행했다. 실제 NAS 토큰은 사용자가 입력한 기기에만 있으며 이 개발 환경에는 없다. 실제 NAS 업로드·휴지통·썸네일 설치와 다운로드 결과를 검증했다고 주장하지 않는다. 기존 `nas-photo-test/` 파일·서버·터널은 보존했다.

가족별 로그인·초대·권한, 여행/성장 기록 영구 DB, 사진을 개별 기록에 연결하는 영구 참조, GPS 자동 여행 핀은 미구현이다. 예시 여행 핀은 예시 데이터 좌표로 표시하며 NAS 파일에서 추론하지 않는다. GitHub Pages는 정적 UI만 호스팅하며 NAS API는 NAS에서 실행한다. Quick Tunnel은 임시 주소이고 재시작 시 바뀔 수 있다. 주소가 바뀌면 연결 설정의 주소만 수정하고 토큰 칸을 비워 저장 토큰을 재사용한다.
