# 메인 화면의 NAS 사진 자동 연결

2026-11-13: NAS 갤러리만 연결되고 나머지는 예시 사진을 사용하던 구조를 수정했다. 이 기능은 **기존 읽기 전용 API**로 동작한다. NAS 설치나 쓰기 권한 변경이 필요하지 않다.

## 사용 순서

1. 기존 NAS 연결을 유지한 채 홈에 접속한다. 저장된 연결이 복원되면 홈이 실제 NAS 사진 모드로 전환된다. 대표 사진과 사진 모음은 `/photo` 및 하위 폴더에서 자동으로 골라 표시한다. 홈에 쓸 범위를 줄이려면 **홈 사진 폴더 변경**을 한 번 누른다.
2. **여행지도 → 우리 여행 사진 → 사진 폴더 연결**에서 여행 사진 폴더를 한 번 선택하고 **이 폴더 연결**을 누른다. 하위 폴더 사진도 자동으로 표시된다.
3. **성장앨범 → 다온 / 라온 / 함께 → 사진 폴더 연결**에서 각 앨범에 해당하는 폴더를 한 번씩 지정한다. 사진을 개별 등록하거나 이동할 필요가 없다. 서로 다른 앨범에 같은 폴더를 지정하면 같은 사진이 나오는 것이므로 실제 분류에 맞춰 선택한다.
4. 폴더 안에 사진이 추가되면 다음 방문/화면의 **새로 불러오기**에서 확인한다. 화면을 열어 두면 보이는 앨범을 60초 간격으로 다시 조회한다. 이 기능은 파일 목록 순서로 일부 사진을 미리보며 촬영일 순서의 '최신 사진'을 보장하지 않는다.
5. **이 폴더의 전체 사진 보기**를 누르면 NAS 갤러리의 동일한 폴더로 이동한다. 갤러리에서는 스크롤로 나머지 목록과 미리보기를 계속 불러온다.

기존에 수동으로 고른 홈 대표 사진은 우선 유지한다. 대표 사진의 **자동 대표 사진 사용**을 누르면 자동 선택으로 돌아간다. 홈의 여행/성장 입구 표지도 각 연결 폴더에서 자동으로 가져온다. 성장 표지는 함께 앨범을 우선하고, 없으면 연결된 다온/라온 앨범을 사용한다.

## 자동화되는 범위와 아직 없는 정보

- 자동: 사진 목록 탐색, 하위 폴더 미리보기, 홈 사진·앨범 표지, 여행/성장 사진 모음, 선택한 폴더의 새 목록 갱신, 해당 폴더의 전체 갤러리 진입.
- 한 번 설정: 여행·다온·라온·함께에 어떤 폴더를 사용할지. 홈은 기본 전체 탐색이며 원하는 경우만 범위를 지정한다.
- 미구현: EXIF/촬영일/GPS 수집, 얼굴로 아이 구분, 국가·도시별 여행 핀 자동 생성, 실제 나이별 타임라인, 실제 여행/성장 이야기 영구 저장. 현재 API에는 이런 분류 정보가 없으며 폴더명/파일명을 실제 촬영 장소·아이 신원·나이로 단정하지 않는다.
- 연결된 여행 화면은 실제 사진을 기본으로 표시한다. 기존 지도/여행기록/버킷리스트는 **예시** 탭에 구분한다. 성장 기록/나이 타임라인 예시는 접을 수 있는 별도 영역이다. 실제 NAS 사진을 예시 여행/성장 기록에 끼워 넣지 않는다.
- 홈에 예시 통계를 실제 수치로 표시하지 않는다. 탐색한 미리보기 수는 전체 NAS 사진 개수도 실제 여행 횟수도 아니다.

## 탐색과 로딩

NAS 전체를 일괄 내려받거나 별도 색인 서버를 설치하지 않는다. 홈 미리보기는 최대 8개, 여행/성장은 최대 12개이며 전체 사진은 기존 NAS 갤러리에서 본다. 미리보기 탐색은 최대 16번 목록 요청/32개 폴더/8단계 하위 폴더 범위로 제한한다. 큰 NAS에서 기본 탐색으로 사진을 못 찾으면 실제 사진이 있는 가까운 폴더를 지정한다. 제한에 도달하거나 일부 하위 폴더를 못 읽으면 화면에서 알린다.

사진 요청은 앨범에서 동시에 2개씩 수행한다. 새 API의 썸네일 기능이 있으면 사용하고, 없으면 기존 원본 사진 API를 사용하므로 기존 서버에서는 데이터 사용량이 클 수 있다. JSON 목록 캐시는 60초다. 자동 갱신은 먼저 목록만 비교하고 표시할 경로/revision이 바뀔 때만 이미지를 다시 요청한다. 변동이 없으면 원본 사진을 매분 재다운로드하지 않는다. 화면 이동/연결 변경 때 이전 화면의 Blob URL과 불필요한 참조를 해제한다. 인증이 종료되면 NAS 사진을 화면에서 지우고 명확하게 구분된 예시 모드로 돌아간다. 사진을 GitHub에 게시하지 않는다.

## 설정 저장과 연결 주소 변경

폴더 설정은 별도 `our-story-album-folders-v1` IndexedDB에 AES-GCM으로 암호화한다. 기존 연결 기억 및 수동 대표 사진 DB를 변경하거나 삭제하지 않는다. 설정은 이 브라우저에서만 기억하며 다른 기기에는 동기화되지 않는다. 사용자가 지정한 사진 경로를 공개 Git이나 localStorage에 기록하지 않는다. 저장 실패 시 연결 완료로 표시하지 않는다. 동일 origin 스크립트로부터 격리하는 서버 인증의 대체 수단은 아니다.

연결 origin별로 설정을 분리한다. Quick Tunnel 주소가 바뀌면 다른 NAS일 수 있어 이전 폴더 설정을 임의로 옮기지 않는다. 같은 NAS의 새 주소인 경우 현재는 폴더를 다시 지정해야 한다. 고정 터널과 기기 간 설정 동기화는 별도 후속 작업이다.

## 검증 범위

- JS 총 51개 통과: 이전 인증/암호화/파일 동작 41개, 공유 썸네일 큐/취소 2개와 자동 탐색/경로/바인딩/예산/인증 실패/오래된 응답 폐기 8개.
- 별도 가상 NAS와 QA DB에서 실제 앱 코드를 사용해 홈 대표 사진/사진 8개/앨범 표지 자동 연결을 확인했다.
- 여행 폴더 한 번 지정 후 하위 폴더 사진 8개 자동 표시, 다온/라온/함께 폴더 독립 선택·전환, 새 문서에서 설정 복원, 라온 사진 추가 후 4→5개 갱신, 전체 사진 보기에서 같은 폴더로 이동을 확인했다.
- 구형 capabilities 404 API에서도 기존 원본 image 경로로 자동 앨범 4장 표시 확인. 재연결 중 중단된 로딩 복구를 수정하고 재검증했다. 연결 해제 후 홈의 Blob 사진 0개/예시 모드 복귀 확인.
- 390px 모바일 iframe에서 콘텐츠 375px, 가로 넘침 없음, 성장 대표 사진 300px, 버튼 화살표 0개 확인.
- 실제 NAS 토큰·사진은 이 개발 환경에 없으므로 실제 사용자 NAS의 자동 탐색/이미지/성능은 아직 검증하지 않았다. NAS 서버·사진·기존 프로젝트는 변경하지 않았다.
