# 편지지 선택

- 부모의 편지 작성/수정에서 코드로 직접 그린 20종 편지지를 미리 보고 선택한다. 색상·간단한 SVG 꽃/잎/별 장식은 로컬 CSS 안에 있고 외부 이미지/라이선스 키/네트워크 요청을 추가하지 않는다.
- 기존 NAS의 엄격한 성장 기록 스키마를 유지한다. 편지는 기존 `body` 문자열에 `[OUR-STORY-LETTER:v1:<허용된 디자인 ID>]`와 빈 줄을 붙여 저장한다. 기본 크림 편지지는 보통의 본문 그대로 저장한다. 디자인 ID는 허용목록으로 제한한다. 이 형식은 HTML이 아니며 실행하지 않는다.
- `readLetter`는 알려진 형식만 분리한다. 목록 미리보기/읽기/수정에는 본문만 표시하고 디자인은 data-paper 허용값으로 적용한다. 기존 일반 본문이나 알 수 없는 표식은 원문으로 보존한다. 사용자가 같은 표식으로 시작하는 본문을 직접 쓴 경우에도 한 번 더 감싸 원문을 보존한다.
- 총 길이는 기존 서버 제한 10,000자를 유지한다. 새 편지의 입력 상한은 표식 공간을 남겨 9,900자다. 기존 긴 편지의 디자인 변경 시 초과하면 내용을 지우지 않고 안내한다.
- 기록 DB 백업에 본문과 디자인 정보가 함께 남는다. 오래된 웹 클라이언트/원시 DB를 직접 읽는 도구에는 표식이 보일 수 있다. 추후 정식 문서 스키마 확장 시 이 버전 형식을 이관할 수 있다. NAS 서버 업데이트는 필요 없다.
