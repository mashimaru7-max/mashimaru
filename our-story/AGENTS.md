# 우리라는 이야기 — 구현 기준

- 사용자 확정: 2026-11-13 제공한 인터랙션 참고 이미지의 패턴을 이 프로젝트의 지속적인 기준으로 삼는다. 이미지의 어두운 보라색이나 네온 색상은 따라 하지 않는다. 아이보리·크림·골드의 가족 앨범 분위기를 유지한다.
- 참고 패턴: 반응형/비대칭 사진 배치, 탭, 모달, 드롭다운, 툴팁, 드로어, 토스트, 캐러셀, 로딩 스켈레톤, 호버, 스크롤 리빌, 순차 등장, 부드러운 상태 전환, 작은 피드백.
- 각 기능에 필요한 패턴만 적용한다. 패럴랙스·강제 스크롤 스냅·유리 효과를 모든 화면에 붙이지 않는다. 정보 접근과 읽기를 우선한다.
- 모바일에는 호버 없이도 동작하는 터치 피드백을 제공한다. 키보드 포커스를 유지하고 reduced-motion 설정을 존중한다. 로딩 스켈레톤은 실제 비동기 로딩이 있을 때 적용하며 가짜 지연을 만들지 않는다.
- Leaflet 마커의 바깥 요소 transform은 지도 좌표용이다. 핀 모양에 필요한 회전·애니메이션은 내부 SVG/자식에만 적용한다.
- 기존 nas-photo-test와 NAS 배포·원본 사진은 승인 없이 변경하지 않는다. NAS 호환성 시험은 임시 데이터와 로컬 테스트 서버만 사용한다.
- 가족 데이터가 없는 예시 모드와 실제 데이터는 명확하게 구분한다. 인증 UI만으로 비공개가 구현되었다고 주장하지 않는다.
- 2026-11-13 사용자 변경 요청: 가족 로그인 도입은 보류하고 NAS 주소·토큰을 이 기기에서 기억하여 자동 재연결한다. 공개 Git에는 실제 비밀을 넣지 않는다. IndexedDB의 암호화 저장과 삭제 기능을 유지하며, 저장 실패를 성공처럼 표시하지 않는다. 기존의 '항상 메모리에만 보관' 정책으로 임의로 되돌리지 않는다.

- 2026-11-13 사용자 확정: 모든 버튼과 이동 링크에서 장식 화살표를 쓰지 않는다. 홈 CTA, 앨범 카드, 기록 상세, NAS 다운로드/폴더까지 적용한다. 방향만 표시하던 버튼은 ‘상위 폴더’처럼 기능을 설명하는 텍스트로 바꾼다. 컴포넌트 참고 이미지의 일부 패턴 적용과 전체 구현을 구분하여 보고한다.
- 2026-11-13 사용자 요구: NAS 연결은 갤러리에 그치지 않고 메인 홈·여행·성장 화면의 실제 사진으로 이어져야 한다. 사진을 하나씩 지정하게 하지 않는다. 홈은 자동 탐색, 분류별 앨범은 폴더 한 번 연결 방식으로 유지한다. 실제 장소·촬영일·아이·나이를 API 정보 없이 추정해 예시 기록과 섞지 않는다. 관련 경계는 docs/AUTO-ALBUMS.md에 기록한다.
- 2026-11-13 사용자 폴더 구조 반영: 사진은 연도 폴더 아래 같은 기본 이름과 선택적인 숫자 접미사로 나뉘어 있다. 설명의 #는 실제 문자가 아니라 숫자 자리였다. 이름 규칙은 기본 이름 그대로/숫자 접미사를 함께 찾고 다른 글자 접미사는 제외한다. 기존 고정 폴더 설정과 기기별 암호화 저장은 유지한다. 사진/폴더를 NAS에서 재정리하지 않는다.

- 2026-11-13 사용자 변경 요청: 가족마다 설정할 필요 없도록 앨범 폴더·이름 규칙·홈 대표사진은 인증된 NAS 공통 설정에 저장한다. 기존 기기별 암호화 설정은 최초 이관 자료로 유지한다. 접속 주소·토큰의 기기별 암호화 저장은 유지한다. 구버전 서버에서 기기 저장을 가족 공통 저장 성공처럼 표시하지 않는다.
- 2026-11-13 UI 수정: 첨부한 원안의 따뜻한 크림 종이·피치빛·식물·들꽃·사진 액자 분위기를 유지한다. 대표 사진 위에 제목/설정 버튼으로 얼굴을 가리지 않는다. 임시 문자 아이콘 대신 로컬 SVG 아이콘을 쓴다. 버튼/메뉴에 상시 inset shadow를 적용하지 않는다.
- 사용자는 가벼운 문구·색상·간격 수정의 과도한 검증과 토큰 소모를 원하지 않는다. 해당 변경 부분만 짧게 확인하고 배포하며 무관한 전체 테스트를 반복하지 않는다.

- 2026-11-13 공통 화면 1단계: 지원 NAS에서는 `/api/album-index`의 영구 SQLite 사진 목록과 고정 정렬을 사용한다. 설정·목록·썸네일 캐시는 `/settings`에 두고 사진 마운트는 읽기 전용으로 유지한다. 구버전의 기기별 탐색을 공통 목록 성공처럼 표시하지 않는다. 폴더/파일 쓰기 기능 활성화는 이번 범위에 포함하지 않는다.

- 2026-11-13 가족 공용 계정 확정: 아이디는 `오니둥이`. 비밀번호는 기존 토큰으로 연결된 기기의 최초 설정 화면에서 HTTPS로 입력받고 NAS에 scrypt 해시만 보관한다. 계정 설정 후 새 API의 기존 토큰 인증을 차단한다. 세션은 서버 검사·만료·로그아웃 폐기를 구현하고 클라이언트는 비밀번호를 저장하지 않는다. NAS 공개 접속 주소는 family-config.mjs에서 제공하며 기본 로그인 화면에 긴 주소/토큰 입력을 요구하지 않는다. 기존 사진 테스트 API는 별도 승인 없이 중단하지 않는다.

- 2026-11-13 성장앨범 구성 확정: 탭 순서는 함께/다온/라온, 새 진입 기본값은 함께. NAS 자동 사진은 함께 탭만 연결하고 개인 탭은 성장 일기·아이의 말·부모 편지·키/몸무게의 기록장으로 구성한다. 개인 사진 폴더나 얼굴 식별로 자동 분류한다고 표현하지 않는다. 실제 기록과 접힌 예시 입력 체험을 명확히 구분한다.

- 2026-11-14 성장 기록 영구 저장 확정/구현: 개인 기록장은 활성 입력폼과 NAS `/settings/journal.sqlite3`를 사용한다. 날짜·작성자 표시·종류별 본문과 최대 6장 NAS 사진 참조를 저장하고 서버 검증, revision 충돌, UUID 생성 재시도 중복 방지, 기록 휴지통/복원을 유지한다. 사진 원본은 읽기 전용으로 보존하며 `/api/journal-backup`은 기록 DB만 내보낸다. 예시 입력과 실제 저장을 섞지 않는다. 실제 영상/여행 ID 연결, 백업 복원 UI는 미구현이다.

- 2026-11-14 사용자 승인: 갤러리 사진 업로드·다운로드·휴지통·복원 및 폴더 생성/이름 변경/이동 단계로 진행한다. 새 API의 사진 쓰기는 ENABLE_WRITES=1과 /photos:rw 및 실제 NAS ACL을 모두 확인한 후 테스트 폴더부터 사용한다. 기존 서버/터널과 NAS 원본을 자동 조작하지 않는다. 동일 이름 덮어쓰기는 제공하지 않는다. 영구삭제는 아래의 명시적 휴지통 선택 절차만 허용한다. 폴더 휴지통은 아래 사용자 확장 요청을 따른다. 폴더 이동은 서버의 영구 작업 내역으로 설정/성장 기록 사진 연결을 복구하며, renameat2 안전 이동 미지원이면 거부한다. 먼저 빈 임시 폴더로 안전한 복원을 확인하지 못하면 사진 휴지통 기능도 막는다. 시스템/휴지통/스냅샷 경로와 symlink 경유 조작은 금지한다.

- 2026-11-14 사용자 확장 요청: 갤러리에서 다중 사진/폴더 선택과 폴더째 휴지통을 지원한다. 전체 선택은 현재 로딩된 항목으로 제한하고 폴더는 하위 모든 내용을 포함함을 확인 화면에 표시한다. 순차 일괄 요청은 중지/권한/네트워크 오류에 미처리 항목을 남기고 성공을 과장하지 않는다. 폴더 원본을 휴지통에 보존하고 원래 위치 충돌 시 합치기/덮어쓰기를 하지 않는다. 폴더 복원 시 성장 기록의 사진 참조도 확인해 재연결한다. 영구삭제는 아래 사용자 추가 승인 범위만 허용한다.

- 2026-11-14 사용자 추가 승인: 휴지통의 명시적으로 선택한 사진/폴더만 공용 비밀번호 재확인 후 서버가 발급한 세션 귀속·120초·일회용 확인권과 마지막 삭제 확인으로 영구삭제한다. 원본 경로 직접 삭제/전체 휴지통 자동 비우기는 제공하지 않는다. 폴더 하위 전체 삭제·웹 복원 불가·중단 시 일부 삭제 가능성을 표시한다. 실제 NAS 파일은 개발/검증 과정에서 삭제하지 않고 임시 테스트 데이터만 사용한다.

- 2026-11-14 영상 지원 승인: 갤러리에 MP4/M4V/MOV/WebM 목록·브라우저 첫 장면·Range 재생·원본 다운로드·최대 4GiB 분할 업로드/이어 올리기·기존 이동/휴지통/복원을 연결한다. 홈/성장 사진 자동 앨범·대표사진·기록 사진 참조는 계속 사진만 받는다. 영상 자동 변환/얼굴 판별은 하지 않는다. 브라우저 미지원 코덱은 다운로드로 안내한다. 토큰/세션을 URL에 넣지 않고 서비스 워커와 페이지 메모리에서 해당 탭에 묶어 중계하며 캐시/디스크에 인증·영상을 저장하지 않는다. 원본 삭제 검증은 임시 파일만 사용한다. 실제 NAS/모바일 브라우저 재생 확인은 사용자에게 요청한다.

- 2026-11-14 서버 영상 썸네일 승인: ffmpeg가 설치된 API 이미지 또는 읽기 전용 /ffmpeg-runtime 추가 폴더로 JPEG 첫 장면을 생성한다. 실행은 한 번에 하나, 저우선순위·소프트웨어 1스레드·20초·16MP 상한으로 제한하고 외부 MOV 참조/네트워크 입력을 거부한다. /settings/video-thumbnails에 최대 256MiB 캐시하며 원본 revision 변경 시 다시 생성한다. 브라우저 재생 지원과 서버 JPEG 생성을 분리한다. 기존 컨테이너/볼륨/터널/계정을 삭제하거나 사용자 NAS를 자동 변경하지 않는다. 사용자에게 실행 권한이 보존되는 tar 설치 파일과 GUI 폴더 매핑 단계를 제공한다.

- 2026-11-14 영상 다운로드 호환 수정: 다운로드는 페이지/서비스 워커에 묶인 재생 URL을 사용하지 않는다. 인증된 POST로 2분·영상 한 파일·GET 한 번만 가능한 티켓을 발급하고 실제 NAS 첨부 스트림으로 보낸다. URL에 가족 세션/토큰을 넣지 않는다. 티켓 발급과 사용/스트림 중 세션 유효성, 원본 revision을 검사한다. HEAD는 소비하지 않고 GET은 Range를 무시해 원본 전체를 200으로 전송한다. 기존 재생/썸네일/ffmpeg 마운트는 유지한다.

- 2026-11-14 실제 여행 페이지 구현: 로그인한 여행 화면은 예시 기록과 섞지 않고 NAS /settings/travel.sqlite3의 여행기/버킷리스트를 사용한다. 직접 선택한 지도 위치와 국가/도시/날짜, 동행 가족, 작성자 표시, 가족 한마디, 선택한 NAS 폴더를 저장한다. 사진에서 장소/GPS/여행일을 추정하지 않는다. 지도 세계/국내·검색·연도·기록 휴지통·홈 최근 여행·통계를 실제 기록으로 연결한다. 폴더 연결은 원본을 수정하지 않으며 FileManager의 영구 이동 계획에 여행 폴더 참조도 포함해 이름/위치 변경 후 복구한다. 새 API 미설치 시 저장 성공처럼 표시하지 않고 업데이트를 안내한다. 기존 공통 여행 사진 모아보기와 로그인 전 예시는 유지한다.

- 2026-11-14 웹 전용 정리: 서버 업데이트 없이 기본 화면의 샘플 기록/가상 통계/반복 개발 안내를 제거한다. 샘플은 하단 ‘화면 둘러보기’로 명시적으로 선택했을 때만 보이고 실제 NAS 사진/기록과 섞지 않는다. 로그인 전에는 안내/로그인 화면, 로그인 후에는 실제 가족 보관함과 기록을 기본으로 한다. 모바일 900px 이하 하단 4개 메뉴, 44px 터치 영역, 작은 화면 2열 사진/입력 글자 16px/안전 영역과 하단 시트를 사용한다. 갤러리는 추가·선택을 우선하고 관리 기능은 더보기에 둔다. 구형 여행 서버에서도 기존 여행 사진을 볼 수 있게 유지한다. 서버 코드/볼륨/계정은 이 작업에서 변경하지 않는다.

- 2026-11-14 촬영정보/갤러리 필터: 웹은 전체·사진·영상 필터를 제공하고 폴더는 탐색을 위해 유지한다. 필터 후 클릭·선택 인덱스는 원본 목록 인덱스를 유지하며 필터 변경 시 선택을 해제한다. 메타데이터는 확대 화면에서만 인증된 /api/media-info로 읽는다. 사진 DateTimeOriginal 우선, 없으면 폴더명 연도/월을 ‘폴더 이름 기준’으로 구분하고 파일 수정일/이름을 촬영일로 추정하지 않는다. GPS 좌표는 지도 링크로 제공하고 지역명은 연결된 여행의 지역임을 명시한다. 외부 역지오코딩 요청은 하지 않는다. 영상 EXIF 날짜를 읽는다고 주장하지 않는다. 원본을 변경하거나 GPS를 공개 Git/브라우저 영구 저장에 보관하지 않는다.
