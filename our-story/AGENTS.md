# 우리라는 이야기 — 구현 기준

- 사용자 확정: 2026-11-13 제공한 인터랙션 참고 이미지의 패턴을 이 프로젝트의 지속적인 기준으로 삼는다. 이미지의 어두운 보라색이나 네온 색상은 따라 하지 않는다. 아이보리·크림·골드의 가족 앨범 분위기를 유지한다.
- 참고 패턴: 반응형/비대칭 사진 배치, 탭, 모달, 드롭다운, 툴팁, 드로어, 토스트, 캐러셀, 로딩 스켈레톤, 호버, 스크롤 리빌, 순차 등장, 부드러운 상태 전환, 작은 피드백.
- 각 기능에 필요한 패턴만 적용한다. 패럴랙스·강제 스크롤 스냅·유리 효과를 모든 화면에 붙이지 않는다. 정보 접근과 읽기를 우선한다.
- 모바일에는 호버 없이도 동작하는 터치 피드백을 제공한다. 키보드 포커스를 유지하고 reduced-motion 설정을 존중한다. 로딩 스켈레톤은 실제 비동기 로딩이 있을 때 적용하며 가짜 지연을 만들지 않는다.
- Leaflet 마커의 바깥 요소 transform은 지도 좌표용이다. 핀 모양에 필요한 회전·애니메이션은 내부 SVG/자식에만 적용한다.
- 기존 nas-photo-test와 NAS 배포·원본 사진은 승인 없이 변경하지 않는다. NAS 호환성 시험은 임시 데이터와 로컬 테스트 서버만 사용한다.
- 가족 데이터가 없는 예시 모드와 실제 데이터는 명확하게 구분한다. 인증 UI만으로 비공개가 구현되었다고 주장하지 않는다.
- 2026-11-13 사용자 변경 요청: 가족 로그인 도입은 보류하고 NAS 주소·토큰을 이 기기에서 기억하여 자동 재연결한다. 공개 Git에는 실제 비밀을 넣지 않는다. IndexedDB의 암호화 저장과 삭제 기능을 유지하며, 저장 실패를 성공처럼 표시하지 않는다. 기존의 '항상 메모리에만 보관' 정책으로 임의로 되돌리지 않는다.
