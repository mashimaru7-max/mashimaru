# 오리팡: 전설 각성

모바일 웹용 매치3 퍼즐 프로토타입. 현재는 1단계 `오리마을`만 구현되어 있습니다.

## 구현 기능

- 7×7 보드, 오리 5종
- 스와이프 및 연속 탭 교환
- 가로·세로 3개 이상 및 2×2 정사각형 매치
- 직선 4개 줄 제거, 정사각형 4개 3×3 폭발, 직선 5개 동일 종류 제거 특수오리
- 특수오리 단독 탭·일반 오리와 스와이프 즉시 발동, 특수끼리 연쇄 조합
- 실제 이동 거리 기반 교환·복귀·낙하 애니메이션과 자동 연쇄
- 75초 점수 경쟁과 기기 내 최고 기록 저장
- 게이지 충전 후 10초 전설 각성: 상위 오리 5종 변환, 점수 2배
- 유효 이동이 없을 때 자동 셔플
- 모바일·폴더블 대응 레이아웃
