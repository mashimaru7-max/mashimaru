# 오리팡: 전설 각성

모바일 웹용 5단계 점수 경쟁형 매치3 퍼즐.

## 구현 기능

- 7×7 보드, 오리 5종
- 스와이프 및 연속 탭 교환
- 가로·세로 3개 이상 및 2×2 정사각형 매치
- 직선 4개 로켓, 정사각형 4개 프로펠러, T·L형 TNT, 직선 5개 태양 특수
- 특수오리 단독 탭·일반 오리와 스와이프 즉시 발동
- 로켓·TNT·프로펠러·태양의 모든 2개 조합에 전용 범위와 합체 연출 적용
- 실제 이동 거리 기반 교환·복귀·낙하 애니메이션과 자동 연쇄
- 5개 난이도 선택, 단계별 최고 기록·종합 기록·점수 해금
- 물방울과 잠금 오리 장애물
- 단계별 60~75초 점수 경쟁과 기기 내 기록 저장
- 게이지 충전 후 10초 전설 각성: 상위 오리 5종 변환, 점수 2배
- 유효 이동이 없을 때 자동 셔플
- 모바일·폴더블 대응 레이아웃
