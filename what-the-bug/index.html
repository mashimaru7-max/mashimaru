HOW TO PLAY

눈송이의 몸짓 수업

  1. 후보 카드 6장의 특징과 벌레를 모두 같이 살펴봐.
  2. 출제자가 기기를 가져가 비밀 주사위를 확인해. 두 숫자가 같은 카드여도 괜찮아.
  3. 문제를 외우고 정답을 숨긴 뒤, 말 없이 몸짓과 표정으로 표현해.
  4. 정답을 외친 사람의 이름을 누르고 출제자가 정답·오답을 판정해. 각자 한 번씩만 도전할 수 있어.
  5. 성공하면 출제자와 정답자가 토큰을 하나씩 받아. 모두 틀리거나 포기하면 보상 없이 다음 차례!
  6. 3~6명은 각자 3번씩 출제한 뒤 별 합계로 우승을 정해. 2명은 각자 5번, 총 10문제의 공동 성공 수를 확인해.
눈송이 가족판 안내

왓더벅의 조합·몸짓 놀이를 바탕으로 만든 비공식 가족용 변형이야. 제시어와 그림은 직접 만들었고, 후보는 한 바퀴마다 교체해. 별 1·2·3개는 각 1/3 확률이며 원작 토큰 구성과 달라. 기본 제한시간은 없어. 한 기기를 돌려 쓰니 비밀 확인 때는 다른 사람이 화면을 보지 않도록 해줘.
