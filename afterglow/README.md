# AFTERGLOW · 달빛 땅따먹기

한 손가락으로 조작하는 모바일 영역 점령 게임입니다.

## 플레이

https://mashimaru7-max.github.io/mashimaru/afterglow/

- 아래 조작 영역 어디든 터치하면 플로팅 스틱이 나타납니다. 6px 이상 살짝 밀면 상하좌우로 움직입니다.
- 엄지를 멀리 옮기면 스틱 중심도 따라 움직입니다. 이동 반경은 28px이고 대각선 경계에는 방향 흔들림 보정이 있습니다.
- 손을 떼면 그린 길을 거슬러 안전지대로 자동 복귀합니다. 복귀 중에도 남은 선은 적의 공격을 받습니다.
- 빈 영역으로 나가면 자동으로 선을 긋습니다.
- 내 땅으로 돌아오면 적이 없는 영역을 점령합니다.
- 적이 미완성 선에 닿거나 자기 선을 가로지르면 목숨이 줄어듭니다.
- PC에서는 방향키로 이동하고 스페이스바로 일시정지합니다.
- 이동 속도는 느리게 / 보통 / 빠르게 중 선택할 수 있습니다.

기본 목표는 모든 스테이지에서 95%입니다. 클리어 후 99% 보너스 도전을 선택하면 같은 판을 계속 플레이하며, 99% 이상 점령하면 보너스 일러스트와 5,000점을 획득합니다. 한 번에 99%를 넘겨도 즉시 해금됩니다. 스테이지가 진행되면 적 수와 속도, 점령 목표가 올라갑니다. 추격형 적은 미완성 선을 향해 가속하며 주황색으로 바뀌고, 배회형 적은 주기적으로 방향과 속도를 바꿉니다.

## 로컬 실행

이 폴더에서 `python3 -m http.server 8000`을 실행하고 http://localhost:8000 에 접속합니다. 모듈 스크립트 때문에 HTML 파일을 직접 여는 대신 HTTP 서버를 사용합니다.

## 테스트

Node.js가 설치된 환경에서 `npm test`를 실행합니다. 추가 패키지는 필요하지 않습니다.

영역 분할, 여러 적이 있는 공간 보존, 스테이지 전환, 선 되돌리기와 자기 선 충돌, 적 충돌, 일시정지, 적의 벽 반사를 검사합니다.

## 파일

- `index.html`: 게임 화면
- `style.css`: 모바일 화면과 터치패드
- `app.js`: 입력 처리, 그림 표시, 효과음
- `engine.js`: 영역 점령과 충돌 규칙
- `pool.jpg`: 첫 번째 수영장 배경 일러스트
- `tests/engine.test.js`: 게임 규칙 테스트

`bonus.jpg`는 99% 보너스 수영복 일러스트입니다.

## 관리자 그림·라운드 설정

하단 관리자에서 지정 비밀번호로 로그인합니다. 기본/99% 보너스 그림, 목표 점령률(50~98%), 제한시간(0=무제한), 적 수(1~12), 적 속도(0.25~3배), 라운드 수(1~20)를 편집합니다. 그림·라운드 설정 저장을 눌러 적용합니다. 게임 설정은 새 게임부터 적용되며 99% 보너스 목표는 고정입니다.

`server-config.js`의 `API_URL`을 배포된 API 주소로 설정하면 모든 기기가 같은 그림·라운드를 사용합니다. 서버 실행과 저장 방식은 `server/README.md`에 설명합니다. 저장 서버가 연결되어 있으며 관리자에서 저장한 그림과 라운드 설정은 모든 기기에 적용됩니다. 주소가 비어 있을 때만 브라우저 저장 모드로 작동합니다. UI에 저장 방식을 표시합니다. 서버 연결 실패 시 로컬 저장으로 몰래 전환하지 않습니다.
