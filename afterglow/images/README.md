# 그림 올리는 폴더

| 용도 | 파일 이름 예시 |
|---|---|
| 1라운드 기본 | 1라운드.jpg |
| 1라운드 99% 보너스 | 1라운드-보너스.jpg |
| 2라운드 기본 | 2라운드.png |
| 2라운드 99% 보너스 | 2라운드-보너스.webp |

1~20라운드, JPG/JPEG/PNG/WEBP/GIF/AVIF 지원입니다. 한 라운드·용도마다 파일 하나만 둡니다. 바꿀 때 기존 파일을 삭제한 후 새 그림을 올립니다. 기본 그림 파일 개수가 전체 라운드 수가 됩니다. 번호가 빠져 있어도 있는 그림만 번호순으로 플레이합니다. 보너스 그림과 README는 개수에서 제외합니다. 보너스는 선택 사항입니다.

**Add file → Upload files → Commit changes**로 저장하고 Pages 배포가 끝난 후 게임을 새로고침합니다.
