📷 NAS 사진 연결 테스트

Synology DS218+ · 공유 공간 /photo · 읽기 전용 목록 조회

먼저 알아둘 점

GitHub Pages에서 NAS에 직접 접속하면 CORS·인증 쿠키·QuickConnect 제한으로 실패할 수 있어요. 실패하더라도 NAS 자체가 연동 불가능하다는 뜻은 아닙니다.

이 페이지는 NAS 주소와 계정 정보를 저장하거나 외부 서버로 전송하지 않습니다. 다만 로그인 시 입력한 정보는 지정한 NAS 주소로 전송됩니다. 반드시 본인이 관리하는 HTTPS 주소와 전용 읽기 계정만 사용하세요. 관리자 계정은 사용하지 마세요.

    실제 사진 파일과 썸네일은 표시하지 않습니다. 1차 검증은 폴더·파일명 조회까지만 수행합니다. 이 테스트는 정적 웹사이트에서 브라우저 직접 연결이 가능한지 확인하는 용도입니다.
